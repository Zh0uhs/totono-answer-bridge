# TOTONO Answer Bridge

用于《君与彼女与彼女之恋》三択问答阶段的 Windows 桌面答案读取器。

## 工作原理

- 游戏停在无法存档的问答画面时，点击“读取答案”。
- 工具从正在运行的 `totono.exe` 进程内只读提取
  `#miyuki_chara_q[0..29]` 的当前数值。
- 题目展示顺序与游戏内部变量顺序不同，工具内置了正确的题目映射。
- 不启动第二个游戏，不替换 `nss-1.npa`，不修改分辨率，不关闭游戏。
- 首次读取前，如果 `1.00.backup` 不存在，会完整复制当前 `1.00` 存档作为备份。
- 读取本身不会写入存档、游戏目录或进程内存。

## 使用方法

1. 运行安装包或免安装版。
2. 确认游戏目录和存档目录检测正确。
3. 在游戏进入问答画面后启动工具；检测到当前问答变量时会自动读取，
   也可以手动点击“读取答案”。
4. 窗口可置顶或切换紧凑模式，方便边玩边查看。

如果提示没有找到问答变量，请确认游戏仍在问答画面。若游戏以管理员身份运行，
本工具也需要以管理员身份运行。

## 系统要求

- Windows 10/11 x64
- Microsoft Edge WebView2 Runtime
- 游戏版本 1.00 / 1.01 汉化版

## 开发

- Tauri 2
- React + TypeScript
- Tailwind CSS + shadcn/ui
- Lucide Icons

构建：

```powershell
npm run build
npm run tauri build
```
